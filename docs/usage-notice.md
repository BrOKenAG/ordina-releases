## 文件与工程

ordina 会在选定目录建立文件夹、写入项目关联和归档记录。启用归档后，会复制符合策略的素材、校验副本并更新 Resolve 素材引用，源文件保留。旧归档整理可能将已确认的旧副本移入项目内的隐藏回退目录。

使用前应为重要工程和素材保留独立备份。软件按现状提供，可能出现错误，作者不保证特定工作流或存储环境的适用性。

## 数据与网络

模板、保存位置、素材策略及归档状态存储在本机或用户选择的项目目录。Resolve 连接使用本机脚本接口。

检查软件更新时会访问 GitHub Pages 和 GitHub Releases，下载版本清单和更新包。Sparkle 配置关闭系统资料发送；软件未设置独立的统计或账户服务。GitHub 请求由其服务按自身隐私政策处理。

## 安装

当前版本支持 Apple 芯片和 macOS 26+，采用临时签名，尚未经过 Apple 公证。请从仓库 Releases 获取安装包。更新包和清单通过独立的 Ed25519 签名验证来源。
