# 生产写入权限边界

插件发布、上下架及事务恢复和回滚由 Python 发布引擎及生产后端检查正式签名授权、GitHub 服务端仓库写入权限和固定公钥对应的签名能力。软件本体和发布工具的生产写入同样检查官方发布仓库的实际 GitHub 写入权限和可信签名能力；生产写入不依赖 Swift 界面、TOTP 或本地开发者标记。权限在加锁、提交写入及引用更新前复核；GitHub 服务端仍会在每个远端请求时独立拒绝被撤销的权限。

生产后端仅允许官方仓库及指定清单路径。清单签名、发布资产、历史版本及线上结果由现有持久化事务验证；旧的直接清单推送路径已关闭。lab 环境和密钥不能授权生产写入。测试使用隔离凭据或模拟后端，不能证明当前用户实际拥有生产权限。

该机制不能阻止有权控制 GitHub 账户或签名密钥的人绕过工具直接调用 GitHub；GitHub 访问控制与客户端固定公钥的签名验证是最终边界。发布工具 1.3.0 为未签名候选版本，正式签名、线上权限与发布尚未验证或执行。
